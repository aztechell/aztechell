# Azat

Меня зовут Азат, я учитель робототехники, вайбкодер.

Разбираюсь в LEGO EV3, Spike Prime, Arduino, ESP, Raspberry Pi, Jetson Nano.

Вот что я делал:

## WRO

- [WRO_Ruller](https://github.com/aztechell/WRO_Ruller) - линейка для карт WRO. [Live](https://aztechell.github.io/WRO_Ruller/)
- [esp32cam-wro2026-mosaic-reader](https://github.com/aztechell/esp32cam-wro2026-mosaic-reader) - чтение мозаики WRO 2026 через ESP32-CAM.
- [femap](https://github.com/aztechell/femap) - рандомизатор FE WRO. [Live](https://aztechell.github.io/femap/)
- [fe-2025-links](https://github.com/aztechell/fe-2025-links) - ссылки на репозитории WRO FE 2025.

## Arduino / ESP

- [HY-S301-Pybricks](https://github.com/aztechell/HY-S301-Pybricks) - 8-канальный датчик линии HY-S301 для SPIKE Prime / Pybricks.
- [POP-XT_lib_n_board](https://github.com/aztechell/POP-XT_lib_n_board) - board package и библиотека POP-XT для Arduino IDE.
- [esp32-joystick](https://github.com/aztechell/esp32-joystick) - эксперименты с ESP32 и джойстиком.
- [esp-discover-rest](https://github.com/aztechell/esp-discover-rest) - REST-эксперименты для ESP.
- [mbc_code](https://github.com/aztechell/mbc_code) - код для MBC Line-Following Sensor.

## AI

- [Voctarium](https://github.com/aztechell/Voctarium) - локальная расшифровка аудио и видео через faster-whisper.
- [KazEmoTTS](https://github.com/aztechell/KazEmoTTS) - эксперименты с казахским emotional TTS.
- [KazEmoTTS_only_inference](https://github.com/aztechell/KazEmoTTS_only_inference) - inference-версия для KazEmoTTS.
- [reboot](https://github.com/aztechell/reboot) - AI-приложение для изменения внешнего вида на фото через Stability API.
